# Open questions for the client

Every item has a working default already built into the specs (`docs/calculations.md`, `docs/hrms-module-plan.md`). The client may change any default during the build. When an answer arrives, update the spec, then strike the item here.

## Release 1: employees, sites, attendance
1. هل يختلف أجر عامل اليومية نفسه حسب الموقع، أم الاختلاف في البدل فقط؟ *(default: البدل فقط)*
2. نفس السكن ونفس الموقع بأجرة مواصلات مختلفة لعمال مختلفين (مثلاً كفر الدوار ← جوار: 30 و35). هل هذا مقصود؟ *(default: أجرة افتراضية + أجرة خاصة لكل عامل)*
3. هل يأخذ عامل اليومية مواصلات؟ عمود المواصلات = صفر للجميع في أكتوبر. *(default: يُصرف حسب جدول الأجرة)*
4. أي عنوان وتليفون وإيميل هو الحالي: 9 ش علي هيبة - سيدي بشر، أم 5 ش الفتح - بولكلي؟ info@ أم smart@؟
5. من هما صاحبا اسمي البصمة Person-12 و Person-13؟ *(تخميننا: Person-14، Person-15)*
6. لكل موظف: المدير، تاريخ التعيين، القسم، التليفون. هذه البيانات غير موجودة في ملفات الإكسل.
7. اعتماد قائمة المواقع بعد توحيد الأسماء (مثلاً سموحة الدولي/الدولى، العلمين/العالمين، الشيراتون/الشراتون).

## Leave (before building the leave module)
8. هل الإجازة الاعتيادية والعارضة مدفوعة بالكامل؟ وهل المرضية مدفوعة بالكامل أم 75%؟
9. لو انتهى رصيد الإجازات، هل الإجازة الزائدة تُخصم كغياب؟
10. هل يأخذ الموظف الجديد الـ10 أيام كاملة، أم بالنسبة والتناسب حسب تاريخ التعيين؟

## Release 2: payroll
11. هل الـHR ستكتب حصة الموظف وحصة الشركة في التأمينات يدوياً كل شهر؟
12. هل الصرف النقدي بالجنيه الصحيح (بدون قروش)؟
13. اعتماد ملف "الفروق مع الإكسل": كل فرق بين حساب النظام والإكسل، مع الموظف والمبلغ والسبب (الزيادة، خصم التأخير للعمال، المواصلات…).

## Release 3: requests and forms
14. مكافأة نهاية الخدمة: هل تُحسب كسور السنة؟ وما هو "الأجر الشامل" (الأساسي + الحوافز)؟ *(النموذج الحالي يتجاهل الشهور الزائدة)*
15. إذن التأخير: ما الحد الأقصى للمدة (النموذج يقول ساعتين)؟ وكم إذناً مسموحاً في الشهر؟ ونفس السؤال للانصراف المبكر.
16. نموذج الإنذار: نص حر لكل حالة، أم أنواع مخالفات بنصوص جاهزة؟
17. هل يريدون النماذج PDF فقط، أم Word أيضاً للتعديل؟
